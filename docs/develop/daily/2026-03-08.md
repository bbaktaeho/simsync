## notecore (공유 Go 패키지)

- `notecore/note.go` — 노트 CRUD 핵심 로직 (SaveNote, LoadNote, ListNotesByDate, DeleteNote, GetMonthNotes)
  - 날짜별 디렉토리 구조 (`YYYY-MM-DD/<id>.md`)
  - YAML frontmatter 파싱 (title, note_date, is_default, created_at, updated_at)
  - 첫 번째 노트 자동 default 설정
- `notecore/auth.go` — 스텁 인증 (email+password 비어있지 않으면 성공)
- `notecore/note_test.go` — 테이블 드리븐 테스트 8개 작성, 전체 통과
