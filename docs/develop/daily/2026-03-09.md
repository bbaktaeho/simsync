### 프로젝트 구조
```
desktop/lib/
├── main.dart                    # 앱 진입점, 로그인/메인 전환, 테마 모드 관리
├── theme/
│   ├── app_colors.dart          # ThemeExtension 기반 라이트/다크 팔레트
│   ├── app_dimensions.dart      # 레이아웃 상수 (스페이싱, 사이드바, 애니메이션 등)
│   └── app_theme.dart           # ThemeData 빌드 (Manrope + JetBrains Mono)
├── models/
│   └── note.dart                # Note 도메인 모델
├── services/
│   └── note_service.dart        # 로컬 파일시스템 CRUD 서비스
├── screens/
│   ├── login_screen.dart        # 로그인 화면
│   └── document_screen.dart     # 메인 문서 작성 화면
└── widgets/
    ├── calendar_section.dart    # 캘린더 (접기/펼치기)
    ├── note_list_section.dart   # 노트 목록 (태그, 페이지네이션)
    ├── editor_panel.dart        # 마크다운 에디터 (프리뷰 토글, 자동저장)
    ├── markdown_preview.dart    # 마크다운 렌더링
    └── weekly_view_panel.dart   # 주간 문서 함께 보기
```

### 구현된 기능

**1. 로그인 화면**
- 중앙 카드 레이아웃, 이메일/비밀번호 입력
- fade + slide 진입 애니메이션
- 껍데기 인증 (아무 값이든 성공)

**2. 문서 작성 화면**
- 좌측 사이드바 + 우측 에디터 분할 레이아웃
- 사이드바 열기/닫기 토글

**3. 캘린더 (좌측 상단)**
- 월별 캘린더 뷰, 접기/펼치기 가능
- 오늘 날짜 하이라이트 (액센트 테두리)
- 노트 있는 날짜에 dot 표시
- 이전/다음 월 네비게이션
- 날짜 클릭 → 해당 날짜 노트 목록 로드

**4. 노트 목록 (좌측 하단)**
- 선택 날짜의 노트 리스트, 선택된 노트에 좌측 액센트 바
- 태그 chip 표시 (최대 2개 + overflow `+N`)
- 10개 초과 시 페이지네이션
- 호버 효과, [+] 버튼으로 노트 추가

**5. 마크다운 에디터 (우측)**
- 타이틀 입력, 태그 추가/삭제 (인라인 입력 + chip)
- 문서 수정일 표시
- JetBrains Mono 에디터 폰트
- Preview 버튼으로 렌더된 마크다운 보기
- 1초 디바운스 자동 저장
- 하단 상태바 (저장 시각 표시)

**6. 다크/라이트 모드**
- `ThemeExtension<AppColorsExtension>` 기반 테마 시스템
- 다크: `#0F1117` 배경 + `#C4A882` muted sand 액센트
- 라이트: `#F6F8FA` 배경 + `#9C7E56` 진한 sand 액센트
- 상단 우측 해/달 아이콘으로 실시간 전환

**7. 주간 문서 함께 보기 (Weekly View)**
- 캘린더 아래 Weekly View 토글 버튼
- 선택된 날짜가 포함된 주(Mon–Sun)의 모든 노트를 우측 패널에 표시
- 날짜별 구분선 + 노트 카드(렌더된 마크다운) 세로 스크롤
- 노트 카드 클릭 → 해당 노트 에디터로 전환
- 호버 시 편집 아이콘 표시

**8. 사이드바 리사이즈**
- 사이드바-에디터 경계에 드래그 핸들 (마우스 `↔` 커서)
- 드래그로 너비 조절, 최대 화면 40%, 최소 200px
- 150px 이하로 줄이면 자동 접힘
- 드래그/호버 시 핸들 하이라이트 (액센트 색상)

## 로컬 파일 저장 구현

### NoteService (로컬 파일시스템 CRUD)
- 저장 경로: `~/.simsync/documents/YYYY-MM-DD/<uuid>.md`
- YAML frontmatter + 마크다운 본문 형식
- frontmatter 필드: `title`, `note_date`, `is_default`, `tags`, `created_at`, `updated_at`
- CRUD: `loadAllNotes()`, `loadNotesByDate()`, `saveNote()`, `createNote()`, `deleteNote()`
- 빈 날짜 디렉토리 자동 삭제

### UI 연동
- `document_screen.dart`에서 `NoteService` 사용하도록 전환
- 노트 로드: 앱 시작 시 비동기 로드 + 로딩 스피너
- 노트 생성: `NoteService.createNote()` 호출, 파일 즉시 생성
- 노트 수정: 에디터 자동 저장 시 `NoteService.saveNote()` 호출, 파일 즉시 반영
- macOS 샌드박스 비활성화 (`com.apple.security.app-sandbox: false`) — 홈 디렉토리 접근 허용

### 버그 수정
- 노트 목록 헤더의 Notes 카운트가 페이지 내 개수만 표시되던 문제 수정 → 해당 날짜 전체 노트 수(`totalCount`) 표시
