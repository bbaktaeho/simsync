# MVP-001: Local App (Flutter)

## 목표
서버 없이 동작하는 Flutter 앱 (데스크톱 + 모바일).
캘린더 기반 노트 작성의 핵심 경험을 검증한다.
단일 코드베이스로 데스크톱과 모바일 모두 지원한다.

## 현재 상태
- 이전 프로토타입(Wails, Flutter 모바일)은 리셋 시 제거됨
- 문서 전용 상태에서 새로 시작

## 프로젝트 구조

```
simsync/
├── app/                       # Flutter 앱 (데스크톱 + 모바일 단일 코드베이스)
│   ├── lib/
│   │   ├── main.dart
│   │   ├── models/            # 도메인 모델 (Note 등)
│   │   ├── services/          # 비즈니스 로직 (노트 CRUD, 로컬 저장)
│   │   ├── screens/           # 화면 (로그인, 캘린더, 에디터 등)
│   │   └── widgets/           # 공유 위젯
│   ├── test/
│   ├── pubspec.yaml
│   ├── android/
│   ├── ios/
│   ├── macos/
│   ├── windows/
│   └── linux/
├── backend/                   # Go API 서버 (MVP-002부터)
└── docs/
```

Flutter 단일 코드베이스로 데스크톱과 모바일 UI를 모두 구현한다.
플랫폼별 차이(레이아웃, 네비게이션)는 responsive/adaptive 패턴으로 처리한다.

## 이번 MVP에서 만들 것

### 1. 껍데기 로그인 화면
- 이메일/비밀번호 입력 폼 UI만 구현
- 실제 인증 없음 — 아무 값이든 입력하면 메인 화면으로 진입
- 목적: 화면 흐름 확보 + 나중에 실제 인증으로 교체할 자리 마련
- 로그아웃 버튼도 껍데기로 배치

### 2. 캘린더 UI
- 월별 캘린더 뷰
- 이전/다음 월 이동
- 오늘 날짜 하이라이트
- 노트가 있는 날짜에 점(dot) 표시
- 날짜 클릭 → 해당 날짜의 노트 목록 표시

### 3. 날짜 기반 노트 CRUD
- 날짜 선택 시 해당 날짜의 노트 목록 표시
- 첫 노트 생성 시 `is_default: true` 자동 설정 (Default Daily Note 규칙)
- 추가 노트 생성 가능 (`is_default: false`)
- 노트 삭제
- 각 노트에 `note_date`, `created_at`, `updated_at` 저장

### 4. 마크다운 에디터
- Desktop: 분할 뷰 (에디터 + 미리보기)
- Mobile: 전환 뷰 (편집 모드 ↔ 미리보기 모드)
- 제목 입력 필드
- 자동 저장 (1초 디바운스)

### 5. 로컬 저장소
날짜 기반 디렉토리 구조 (로컬 파일 시스템):

```
~/.simsync/documents/        # 데스크톱
{app_documents}/simsync/     # 모바일 (path_provider)
├── 2026-03-08/
│   ├── <uuid>.md          # is_default: true
│   └── <uuid>.md          # 추가 노트
├── 2026-03-09/
│   └── <uuid>.md
└── ...
```

frontmatter 포맷:
```yaml
---
title: 오늘의 작업 기록
note_date: 2026-03-08
is_default: true
created_at: 2026-03-08T10:30:00+09:00
updated_at: 2026-03-08T15:20:00+09:00
---
```

### 6. Responsive/Adaptive 레이아웃
- 화면 크기에 따라 데스크톱/모바일 레이아웃 자동 전환
- Desktop (≥ 768px): 사이드바 + 메인 영역 분할
- Mobile (< 768px): 전체 화면 네비게이션

## 만들지 않는 것
- 실제 서버/DB 연동
- 실제 인증 (JWT 등)
- 멀티 디바이스 동기화
- 태그/검색
- AI 요약

## 구현 순서

### Step 1: Flutter 프로젝트 생성
- [ ] `app/` 디렉토리에 Flutter 프로젝트 생성
- [ ] 데스크톱 플랫폼 활성화 (macOS/Windows/Linux)
- [ ] 프로젝트 구조 설정 (models/, services/, screens/, widgets/)

### Step 2: 도메인 모델 + 로컬 저장 서비스
- [ ] `Note` 모델 정의 (Dart)
- [ ] `NoteService` — 날짜 기반 디렉토리 CRUD
- [ ] `SaveNote`, `LoadNote`, `ListNotesByDate`, `DeleteNote`, `GetMonthNotes`
- [ ] Default daily note 자동 판단 로직
- [ ] YAML frontmatter 파싱
- [ ] 단위 테스트

### Step 3: 껍데기 로그인 화면
- [ ] 로그인 폼 UI (이메일, 비밀번호, 로그인 버튼)
- [ ] 아무 값 입력 → 메인 화면 전환
- [ ] 로그아웃 버튼 → 로그인 화면으로 복귀

### Step 4: 캘린더 + 노트 목록
- [ ] 월별 캘린더 위젯 (7열 그리드)
- [ ] 이전/다음 월 네비게이션
- [ ] 오늘 날짜 하이라이트
- [ ] `GetMonthNotes()` 호출하여 노트 있는 날짜에 dot 표시
- [ ] 날짜 클릭 시 노트 목록 갱신
- [ ] Default note에 ● 표시
- [ ] [+] 버튼으로 추가 노트 생성

### Step 5: 마크다운 에디터
- [ ] Desktop: 분할 뷰 (에디터 + 미리보기)
- [ ] Mobile: 편집/미리보기 전환
- [ ] 제목 입력 필드
- [ ] 자동 저장 (1초 디바운스)

### Step 6: Responsive 레이아웃
- [ ] LayoutBuilder 기반 데스크톱/모바일 분기
- [ ] Desktop: 사이드바(캘린더 + 노트 목록) + 메인(에디터)
- [ ] Mobile: 전체 화면 네비게이션 (캘린더 → 노트 목록 → 에디터)

### Step 7: 통합 테스트
- [ ] 날짜 선택 → 첫 노트 생성 (default) → 내용 작성 → 자동저장
- [ ] 같은 날짜에 추가 노트 생성
- [ ] 다른 날짜로 이동 → 돌아와서 이전 노트 유지
- [ ] 캘린더 dot 표시 정상 동작
- [ ] 로그인 → 메인 → 로그아웃 흐름
- [ ] 데스크톱/모바일 양쪽에서 동일 시나리오 검증
