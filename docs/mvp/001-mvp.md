# MVP-001: Local Desktop & Mobile App

## 목표
서버 없이 동작하는 데스크탑 앱과 모바일 앱.
캘린더 기반 노트 작성의 핵심 경험을 검증한다.
두 플랫폼은 동일한 기능을 제공한다.

## 현재 상태
- Wails 데스크탑 프로토타입 완성 (사이드바 + 마크다운 에디터 + 미리보기)
- 로컬 파일 저장 (`~/.simsync/documents/`)
- 캘린더 UI 없음, 날짜 개념 없음
- 모바일 앱 없음

## 공유 코드 전략
데스크탑과 모바일이 동일한 Go 비즈니스 로직을 공유한다.

```
simsync/
├── notecore/              # 공유 Go 패키지 (노트 CRUD, 저장, 캘린더 로직)
│   ├── go.mod
│   ├── note.go            # Note 도메인 모델 + CRUD
│   ├── calendar.go        # 월별 노트 조회
│   ├── auth.go            # 껍데기 인증
│   └── note_test.go
├── desktop/               # Wails 앱 (notecore 임포트)
│   ├── app.go             # notecore를 Wails에 바인딩
│   ├── main.go
│   └── frontend/
└── mobile/                # Flutter 앱 (notecore via gomobile bind)
    ├── lib/               # Flutter(Dart) UI 코드
    ├── pubspec.yaml
    ├── android/
    ├── ios/
    └── notecore_bridge/   # gomobile bind로 생성된 Go 바인딩
```

`notecore/` 패키지에 비즈니스 로직을 집중하고, desktop과 mobile은 각각 UI 레이어만 담당한다.

## 이번 MVP에서 만들 것

### 1. notecore 공유 패키지
- 노트 CRUD (날짜 기반 디렉토리 저장)
- Default daily note 자동 판단
- 월별 노트 존재 날짜 조회
- 껍데기 인증 (항상 성공)

### 2. 껍데기 로그인 화면 (Desktop + Mobile 공통 기능)
- 이메일/비밀번호 입력 폼 UI만 구현
- 실제 인증 없음 — 아무 값이든 입력하면 메인 화면으로 진입
- 목적: 화면 흐름 확보 + 나중에 실제 인증으로 교체할 자리 마련
- 로그아웃 버튼도 껍데기로 배치

### 3. 캘린더 UI (Desktop + Mobile 공통 기능)
- 월별 캘린더 뷰
- 이전/다음 월 이동
- 오늘 날짜 하이라이트
- 노트가 있는 날짜에 점(dot) 표시
- 날짜 클릭 → 해당 날짜의 노트 목록 표시

### 4. 날짜 기반 노트 CRUD (Desktop + Mobile 공통 기능)
- 날짜 선택 시 해당 날짜의 노트 목록 표시
- 첫 노트 생성 시 `is_default: true` 자동 설정 (Default Daily Note 규칙)
- 추가 노트 생성 가능 (`is_default: false`)
- 노트 삭제
- 각 노트에 `note_date`, `created_at`, `updated_at` 저장

### 5. 마크다운 에디터 (Desktop + Mobile 공통 기능)
- 분할 뷰: 에디터 + 미리보기 (데스크탑)
- 전환 뷰: 편집 모드 ↔ 미리보기 모드 (모바일)
- 제목 입력 필드
- 자동 저장 (1초 디바운스)

### 6. 로컬 저장소 구조
날짜 기반 디렉토리 구조:

```
~/.simsync/documents/
├── 2026-03-08/
│   ├── <uuid>.md          # is_default: true
│   └── <uuid>.md          # 추가 노트
├── 2026-03-09/
│   └── <uuid>.md
└── ...
```

frontmatter 포맷:
```yaml
---
title: 오늘의 작업 기록
note_date: 2026-03-08
is_default: true
created_at: 2026-03-08T10:30:00+09:00
updated_at: 2026-03-08T15:20:00+09:00
---
```

## 만들지 않는 것
- 실제 서버/DB 연동
- 실제 인증 (JWT 등)
- 멀티 디바이스 동기화
- 태그/검색
- AI 요약

## 구현 순서

### Step 1: notecore 공유 패키지 생성
- [ ] `notecore/` 디렉토리 + `go.mod` 생성
- [ ] `Note` 도메인 struct 정의
- [ ] `NoteStore` — 날짜 기반 디렉토리 CRUD
- [ ] `SaveNote(noteDate, id, title, content, isDefault)`
- [ ] `LoadNote(noteDate, id)`
- [ ] `ListNotesByDate(noteDate)`
- [ ] `DeleteNote(noteDate, id)`
- [ ] `GetMonthNotes(year, month)` — 해당 월에 노트가 있는 날짜 목록
- [ ] Default daily note 자동 판단 로직
- [ ] 껍데기 `Login(email, password)` — 항상 성공
- [ ] 단위 테스트

### Step 2: Desktop — notecore 연동
- [ ] `desktop/app.go`를 notecore 호출로 전환
- [ ] 기존 로컬 저장 로직 제거, notecore 위임

### Step 3: Desktop — 로그인 화면
- [ ] 로그인 폼 UI (이메일, 비밀번호, 로그인 버튼)
- [ ] Login() 호출 → 메인 화면 전환
- [ ] 로그아웃 버튼 → 로그인 화면으로 복귀

### Step 4: Desktop — 캘린더 + 노트 목록
- [ ] 월별 캘린더 컴포넌트 (7열 그리드)
- [ ] 이전/다음 월 네비게이션
- [ ] 오늘 날짜 하이라이트
- [ ] GetMonthNotes() 호출하여 노트 있는 날짜에 dot 표시
- [ ] 날짜 클릭 시 노트 목록 갱신
- [ ] 사이드바 하단에 선택 날짜의 노트 목록
- [ ] Default note에 ● 표시
- [ ] [+] 버튼으로 추가 노트 생성

### Step 5: Mobile — Flutter 프로젝트 셋업
- [ ] `mobile/` 디렉토리에 Flutter 프로젝트 생성 (`flutter create`)
- [ ] gomobile bind로 notecore를 .aar(Android) / .xcframework(iOS) 라이브러리로 빌드
- [ ] Flutter에서 notecore 바인딩을 호출하는 플러그인/채널 구성

### Step 6: Mobile — Flutter 화면 구현
- [ ] 로그인 화면 (Flutter/Dart)
- [ ] 캘린더 뷰 (Flutter/Dart)
- [ ] 날짜별 노트 목록 (Flutter/Dart)
- [ ] 마크다운 에디터 (편집/미리보기 전환, Flutter/Dart)
- [ ] 자동 저장 (notecore 호출)

### Step 7: 통합 테스트
- [ ] Desktop: 날짜 선택 → 첫 노트 생성 (default) → 내용 작성 → 자동저장
- [ ] Desktop: 같은 날짜에 추가 노트 생성
- [ ] Desktop: 다른 날짜로 이동 → 돌아와서 이전 노트 유지
- [ ] Desktop: 캘린더 dot 표시 정상 동작
- [ ] Desktop: 로그인 → 메인 → 로그아웃 흐름
- [ ] Mobile: 위와 동일한 시나리오 검증
