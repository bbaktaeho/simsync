# MVP-002: Backend API

> 선행 조건: MVP-001 완료

## 목표
Go 표준 라이브러리 기반 HTTP 서버를 구축하고, PostgreSQL에 데이터를 저장한다.
실제 인증(JWT)을 구현하여 MVP-001의 껍데기 로그인을 대체할 준비를 한다.

## 범위

### 포함
- Go `net/http` 기반 API 서버 (`backend/`)
- PostgreSQL 스키마 마이그레이션 (users, devices, notes 테이블)
- 회원가입 / 로그인 API (JWT 발급)
- JWT 검증 미들웨어
- 노트 CRUD API (날짜 기반)
- Default daily note 자동 판단
- 디바이스 등록 API

### 제외
- WebSocket 동기화
- 태그/검색
- AI 요약
- 프론트엔드 변경 (MVP-003에서 연동)

## 주요 API
```
POST   /api/auth/register
POST   /api/auth/login
POST   /api/devices
GET    /api/notes?date=2026-03-08
GET    /api/notes/{id}
POST   /api/notes
PUT    /api/notes/{id}
DELETE /api/notes/{id}
```
