# MVP-006: AI Summary

> 선행 조건: MVP-005 완료

## 목표
사용자의 일정 기간 노트를 AI로 요약한다.
사용자 동의를 반드시 받은 후에만 AI API를 호출한다.

## 범위

### 포함
- 요약 생성 화면 (기간 선택 + 동의 확인)
- Backend: AI provider 호출 (provider-agnostic 인터페이스)
- summaries, summary_sources 테이블
- 요약 결과 저장 + 조회
- 요약 ↔ 원본 노트 상호 참조

### 제외
- 특정 AI provider 고정 (인터페이스만 정의)
- 자동 요약 스케줄링

## 완료 기준
- [ ] 주간/월간/연간 요약 생성 요청
- [ ] 동의 확인 없이는 API 호출 불가
- [ ] 요약 결과가 별도 저장되고 조회 가능
- [ ] 요약에서 원본 노트로 이동 가능
