# MVP-004: Multi-device Sync

> 선행 조건: MVP-003 완료

## 목표
여러 디바이스에서 동일 계정으로 로그인했을 때, 노트 변경이 실시간으로 반영된다.

## 범위

### 포함
- Backend WebSocket Hub (`nhooyr.io/websocket`)
- 클라이언트 WebSocket 연결 (JWT 인증)
- 노트 변경 시 서버 → 다른 디바이스에 push
- 앱 시작 시 `GET /api/notes/sync?since=<timestamp>`로 미반영 변경 가져오기
- Version 기반 충돌 감지 (409 Conflict → 서버 최신 반영)
- sync_events 테이블 기록
- 상태바에 동기화 상태 표시

### 제외
- 오프라인 큐잉
- CRDT/OT

## 완료 기준
