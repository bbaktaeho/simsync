# SimSync MVP Roadmap

각 MVP 단계는 독립적으로 완성 가능한 단위로 구성한다.
이전 단계가 완료되어야 다음 단계로 진행한다.

| MVP | 이름 | 핵심 목표 |
|-----|------|----------|
| [001](001-mvp.md) | Local Desktop App | 캘린더 + 노트 CRUD + 마크다운 에디터 + 껍데기 로그인 (로컬 저장) |
| [002](002-mvp.md) | Backend API | Go 서버 + PostgreSQL + 실제 인증 + 노트 API |
| [003](003-mvp.md) | Desktop ↔ Server 연동 | 데스크탑 앱을 로컬 저장에서 API 연동으로 전환 |
| [004](004-mvp.md) | Multi-device Sync | WebSocket 실시간 동기화 + 충돌 감지 |
| [005](005-mvp.md) | Tags & Search | 태그 CRUD + 날짜/태그 검색 |
| [006](006-mvp.md) | AI Summary | 주간/월간/연간 AI 요약 (사용자 동의 필수) |
