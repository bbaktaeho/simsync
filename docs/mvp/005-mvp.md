# MVP-005: Tags & Search

> 선행 조건: MVP-003 완료 (MVP-004와 병렬 가능)

## 목표
노트에 태그를 붙이고, 날짜/태그로 검색할 수 있다.

## 범위

### 포함
- Backend: tags, note_tags 테이블 + CRUD API
- 노트 에디터에서 태그 추가/제거 UI
- 사이드바에 검색 패널 (날짜 범위 + 태그 필터)
- 검색 결과 목록 → 노트 클릭 시 에디터에 로드

### 제외
- 전문 검색 (full-text search)
- 태그 자동완성/추천

## 완료 기준
- [ ] 노트에 태그 추가/제거 동작
- [ ] 날짜 범위로 노트 검색
- [ ] 태그로 노트 필터링
- [ ] 검색 결과에서 노트 열기
