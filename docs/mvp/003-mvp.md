# MVP-003: App ↔ Server 연동

> 선행 조건: MVP-001 + MVP-002 완료

## 목표
Flutter 앱의 로컬 저장을 API 연동으로 전환한다.
껍데기 로그인을 실제 JWT 인증으로 교체한다.

## 범위

### 포함
- 로그인 화면에서 실제 API 호출 (register/login)
- JWT 토큰 로컬 저장 및 자동 갱신
- 노트 CRUD를 로컬 파일 → REST API 호출로 전환
- 디바이스 자동 등록
- 네트워크 에러 시 사용자 피드백

### 제외
- 실시간 동기화 (MVP-004)
- 오프라인 편집
- 태그/검색

## 완료 기준
- [ ] 회원가입 → 로그인 → 토큰 저장 동작
- [ ] 노트 CRUD가 서버 API를 통해 동작
- [ ] 앱 재시작 시 토큰 유효하면 자동 로그인
- [ ] 서버 미연결 시 에러 메시지 표시
